# 🎓 Student Dashboard

A modern and responsive Student Dashboard built using React, Vite, JavaScript, and Tailwind CSS.

This project helps students view and manage their academic information through an interactive dashboard interface.

---

## 🚀 Features

### 👤 Profile Section
- Student Profile Information
- Educational Details
- Family Information
- Proctor Information

### 📝 Marks Section
- Semester-wise Navigation
- Subject-wise Selection
- Detailed Internal Marks
- Assessment Records
- Weightage Calculations
- Grade Display for Special Courses

### 📊 Grades Section
- Semester-wise Grade Records
- GPA Information
- Course Grade Tracking

### 📈 Grade History
- Academic Performance History
- Semester Progress Tracking

### 📚 Semester Information
- Fall and Winter Semester Mapping
- Semester Name Reference Popup

---

## 🛠️ Tech Stack

### Frontend
- React.js

- Tailwind CSS

### Routing

  - useState

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/student-dashboard.git
```

Navigate into the project:

```bash
cd student-dashboard
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```

---

## 📦 Build for Production

```bash
npm run build
```

Preview build:

```bash
npm run preview
```
